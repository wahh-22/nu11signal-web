# nu11signal website

## Objective
A fast static website for nu11signal (cyberpunk terminal radio for Apple Music), with its own branding (the null emblem), published on GitHub Pages from the public repo wahh-22/nu11signal-web, ready for the custom domain nu11signal.wahh.dev, with a donation section.

## Decisions (user, 2026-10-01)
- Framework: Astro (static output).
- Repo: public `wahh-22/nu11signal-web`; GitHub Pages via GitHub Actions; first served at https://wahh-22.github.io/nu11signal-web.
- Custom domain `nu11signal.wahh.dev` prepared but not enabled until the user adds the DNS CNAME (`nu11signal` → `wahh-22.github.io`) and verifies the domain in GitHub.
- Donations: "Buy me a coffee"-style button and GitHub Sponsors, links supplied later by the user (placeholders until then).
